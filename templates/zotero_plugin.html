安装步骤

  1. 点击右上角 下载插件，获得 arxiv-daily-importer.xpi。
  2. 打开 Zotero，进入菜单 工具 → 插件。
  3. 点击窗口右上角 齿轮图标，选择 Install Add-on From File...。
  4. 选择刚下载的 arxiv-daily-importer.xpi，确认安装。
  5. 重启 Zotero，等待约 8 秒，今日报告会自动导入。

默认配置

插件默认连接服务地址：{{ public_host }}。 如果你需要换成内网穿透或别的地址，可在 Zotero 的 Run JavaScript 中执行： 

const b = Services.prefs.getBranch("extensions.arxiv-daily-importer.");
b.setStringPref("reportURLTemplate", "{{ public_host }}/download/{date}.html");
b.setStringPref("datesAPI", "{{ public_host }}/api/dates");
b.setIntPref("intervalMinutes", 60);
b.setBoolPref("autoImport", true);
b.setStringPref("defaultCollectionPath", "arXiv/每日精读");

常见问题

安装提示 incompatible / update_url 错误？

Zotero 9 要求插件 manifest 里的 update_url 必须是 HTTPS。本页下载的 xpi 会自动写入：

{{ plugin_update_url }}

请确保该 HTTPS 地址可访问（服务器需设置 WEB_PUBLIC_URL=https://你的域名）。不要用旧的本地 xpi 文件。

历史报告会被一起灌进 Zotero 吗？

不会。首次安装只导入今天，历史日期会被标记为“已处理”而不实际下载。如果你希望补导入某一天，使用菜单里的 导入指定日期的 arXiv 报告...。

会重复导入吗？

不会。已导入的日期被写入 Zotero 偏好 extensions.arxiv-daily-importer.importedDates，下次自动同步会自动跳过。

Zotero 关掉之后还会导入吗？

不会。同步任务依赖 Zotero 运行；下次启动 Zotero 时会自动补齐遗漏的日期。

服务暂时连不上会出什么问题？

插件会静默跳过本轮，下一轮 60 分钟后再尝试，不会反复弹错。
